# sistema-pedidos-cafeteria
## Descripción
Este proyecto es una aplicación interactiva en Python que simula un sistema de gestión de pedidos para una cafetería. Permite a los usuarios consultar un catálogo de productos, agregar ítems con sus respectivas cantidades, revisar el estado de su pedido en tiempo real y calcular la cuenta final incluyendo el porcentaje de propina.

## Requisitos y Tecnologías
- Python 3.x
- Uso de diccionarios, listas, bucles while/for, estructura for/else, validaciones de entrada, formato monetario y f-strings.
